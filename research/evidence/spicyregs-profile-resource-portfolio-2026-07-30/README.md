# Archived SpicyRegs profile-resource portfolio

These files preserve the July 30, 2026 experiment that joined SpicyRegs source
profiles to RefSpec resources and search-oriented choices. They are historical
evidence, not generated RefSpec outputs or current product policy.

The experiment established the 17-profile inventory and informed the later
repository split. Current implementations use:

- RefSpec's source-neutral experimental resource catalog;
- SpicyRegs-owned source-profile and factual resource-applicability files; and
- SpicySearch-owned admission and retrieval policy.

No default RefSpec command reads these archived files.
