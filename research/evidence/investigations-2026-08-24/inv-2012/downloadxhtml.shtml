Click the "directory" link for a list of files in each publication or the "zip" link for a zip file containing all released titles for a publication. Each title of the Code is a separate file, the name of which contains “usc” followed by the title number. A file for a supplement year, such as “(2006 Edition and Supplement III)”, consists of main edition and cumulative supplement data that has been merged into a “virtual main edition” that was current for that year (see About the Code).
